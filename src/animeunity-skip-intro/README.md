# AnimeUnity - Skip Intro (`animeunity-skip-intro.user.js`)

> Lightweight userscript that detects and skips anime opening sequences on AnimeUnity using crowdsourced AniSkip timestamps.

---

## ✨ Features

- **🎯 Exact Timestamp Detection**: Retrieves opening start and end times directly from [AniSkip](https://api.aniskip.com) using the anime's MyAnimeList ID.
- **⚡ In-Player Overlay Button**: Clean "Salta Intro" button appears directly on the video player only while the opening sequence is playing.
- **🖥️ Fullscreen & Normal Mode**: Works seamlessly in both standard view and fullscreen mode on JWPlayer / VixCloud.
- **⌨️ Keyboard Shortcut**: Press `S` during the intro to skip immediately.
- **🪶 Zero Dependencies**: Decoupled from AniList accounts and tokens; works out of the box for all users.
